Description détaillée

Modèle de gestion des bornes de recharge – opérations CRUD sur la table BORNES.

Ce fichier regroupe toutes les fonctions d'accès aux données relatives aux bornes de recharge électrique. Il dialogue avec la table BORNES de la base de données via PDO.

Fonctions disponibles :

  • RecupererListeBorne() : liste publique des bornes
  • GetNomBorne() : nom d'une borne par son identifiant
  • GetBorneParId() : tous les champs d'une borne par son identifiant
  • modele_AjoutBorne() : insertion d'une nouvelle borne
  • SupprimerBorne() : suppression d'une borne par son identifiant
Note
Ce fichier ne contient pas de fonction ModifierBorne() ; celle-ci doit être définie ailleurs ou ajoutée si nécessaire.

Dépendances :

  • modele.inc.php : fonction connexionBdd()

◆ GetBorneParId()

GetBorneParId (   $idBorne)

Retourne l'ensemble des informations d'une borne à partir de son identifiant.

Effectue un SELECT * sur la table BORNES pour la borne demandée. Retourne toutes les colonnes disponibles sous forme de tableau associatif.

Paramètres
int$idBorneIdentifiant unique de la borne (clé primaire de BORNES).
Renvoie
array|null Tableau associatif de la borne si elle existe, null sinon. Les clés correspondent aux colonnes de la table BORNES.
Exceptions
PDOExceptionEn cas d'erreur SQL (interceptée, message affiché, die()).

Insère une nouvelle borne de recharge dans la base de données.

Effectue un INSERT dans la table BORNES avec les six paramètres fournis. Le SSID Wi-Fi et le mot de passe usine sont typiquement fournis par le contrôleur avec des valeurs fixes (ex. fortinet / Projet2026).

Paramètres
string$nomBorneNom d'affichage de la borne.
string$emplacementLocalisation physique de la borne.
string$puissancePuissance maximale de charge (ex. "22kW").
string$ipUsineAdresse IP d'usine de la borne.
string$ssidWifiSSID du réseau Wi-Fi auquel la borne est rattachée.
string$mdpUsineMot de passe usine de la borne.
Renvoie
string ‘'ok’si l'insertion a réussi,'erreur'` sinon.
Exceptions
PDOExceptionEn cas d'erreur SQL (interceptée, message affiché, die()).

◆ RecupererListeBorne()

RecupererListeBorne ( )

Récupère la liste de toutes les bornes (vue publique).

Exécute un SELECT sur la table BORNES et retourne les colonnes id_borne, nom_borne, emplacement, puissance et ip_usine.

Renvoie
array Tableau associatif indexé contenant toutes les bornes. Chaque élément est un tableau associatif avec les clés :
  • id_borne (int)
  • nom_borne (string)
  • emplacement (string)
  • puissance (string)
  • ip_usine (string)
Exceptions
PDOExceptionEn cas d'erreur SQL (interceptée, message affiché, die()).

◆ SupprimerBorne()

SupprimerBorne (   $idBorne)

Supprime une borne de la base de données par son identifiant.

Effectue un DELETE sur la table BORNES pour la borne dont l'identifiant correspond à $idBorne.

Avertissement
La suppression d'une borne peut entraîner des suppressions en cascade si des contraintes de clé étrangère sont définies sur les tables liées (ex. SESSIONS, MESURES).
Paramètres
int$idBorneIdentifiant unique de la borne à supprimer.
Renvoie
string ‘'ok’si la suppression a réussi,'erreur'` sinon.
Exceptions
PDOExceptionEn cas d'erreur SQL (interceptée, message affiché, die()).
