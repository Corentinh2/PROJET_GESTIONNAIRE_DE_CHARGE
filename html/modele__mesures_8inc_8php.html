Description détaillée

Modèle de lecture des mesures de puissance – requêtes sur les tables MESURES et SESSIONS.

Ce fichier regroupe les fonctions de consultation des mesures de puissance enregistrées par les bornes de recharge. Les mesures sont liées aux bornes via la table SESSIONS (relation MESURES → SESSIONS → BORNES).

Fonctions disponibles :

  • GetMesuresParBorne() : historique de puissance sur une plage de dates
  • GetDernieresMesuresParBorne(): les 30 dernières mesures d'une borne

Structure des données retournées par GetMesuresParBorne() :

{
"categories": ["2026-01-01 10:00:00", ...], // horodatages
"series": [
{ "name": "Puissance (kW)", "data": [3.2, 7.1, ...] }
]
}

Dépendances :

◆ GetDernieresMesuresParBorne()

GetDernieresMesuresParBorne (   $idBorne)

Retourne les 30 dernières mesures enregistrées pour une borne.

Effectue une jointure implicite entre MESURES et SESSIONS, filtrée par l'identifiant de borne. Les résultats sont triés par horodatage décroissant (plus récent en premier) et limités à 30 entrées.

Chaque mesure est retournée sous forme de tableau numérique à 4 éléments.

Paramètres
int$idBorneIdentifiant de la borne dont on veut les dernières mesures.
Renvoie
array Tableau indexé dont chaque élément est un tableau numérique :
  • [0] id_mesure (int) : identifiant de la mesure
  • [1] horodatage (string) : date/heure au format Y-m-d H:i:s
  • [2] puissance (float) : valeur de puissance mesurée (kW)
  • [3] id_session (int) : identifiant de la session associée
Note
Le tri est décroissant (du plus récent au plus ancien). Le résultat est limité à 30 lignes.
Exceptions
PDOExceptionEn cas d'erreur SQL (interceptée, message affiché, die()).

◆ GetMesuresParBorne()

GetMesuresParBorne (   $idBorne,
  $debut,
  $fin 
)

Retourne les mesures de puissance d'une borne sur une période donnée.

Effectue une jointure entre MESURES et SESSIONS pour filtrer les mesures appartenant à la borne identifiée par $idBorne, dans l'intervalle [$debut, $fin]. Les résultats sont triés par horodatage croissant.

La structure retournée est compatible avec les bibliothèques de graphiques (ex. ApexCharts, Highcharts) : un tableau categories pour l'axe des abscisses (horodatages) et un tableau series pour les données de puissance.

Paramètres
int$idBorneIdentifiant de la borne (clé étrangère dans SESSIONS).
string$debutDate/heure de début au format Y-m-d H:i:s.
string$finDate/heure de fin au format Y-m-d H:i:s.
Renvoie
array Tableau associatif structuré pour le rendu graphique :
[
"categories" => string[], // liste des horodatages
"series" => [
[ "name" => "Puissance (kW)", "data" => float[] ]
]
]
Retourne des tableaux vides si aucune mesure ne correspond aux critères.
Exceptions
PDOExceptionEn cas d'erreur SQL (interceptée, message affiché, die()).
